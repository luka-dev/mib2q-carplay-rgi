## Finding and data boundary

[`sep_net.py:314`](RETIRED_TOOLS.md#tool-9d28f37ffbb4) samples every source from one cached song/window and only changes seven source gains by ±6 dB. None of reviews 1–42 tested independently timed cross-song source mixtures. This is a data-diversity hypothesis, not evidence yet that the architecture failures were caused by the sampling rule.

The actual seven MoisesDB cache slots are lead vocal, other vocal, drum core, cymbals, percussion, bass and **other**. The latter already combines guitars, keys, piano, strings and more; the current cache cannot remix those instrument families independently. On the PC, the artist-split MoisesDB cache has 240 songs total, of which **176 present TRAIN** songs enter this training path. The original catalog lists 181 TRAIN, but five are absent from this cache. The other 40 DEV and 19 heldout songs must not enter a synthetic training mixture. The 774 teacher-labelled library songs are estimated stems, not independent truth.

[`sep_net_crosssong.py`](RETIRED_TOOLS.md#tool-2aac3eb4bed4) changes only the training sampler for a new 4k run. For a true-stem sample it selects **four distinct TRAIN songs**, with an independent random crop start for each, assigning each song to one source family: vocal slots 0–1, drum slots 2–4, bass slot 5 and eligible `other` slot 6. It then applies the same independent per-slot ±6 dB gains and constructs the mixture and aligned source targets by exact sum. The pseudo-labelled half retains the historical same-song sampler. Fixed DEV validation remains natural, unmodified songs. A local synthetic sampler check verified four distinct paths, independent offsets, slot assignments, tensor shapes and `mixture = eligible + vocal + drums + bass` closure. No training/validation data were read by that smoke test.

The other previously used real-stem corpora are not in the PC's ready seven-slot TRAIN cache. MUSDB18 was deleted locally after earlier work and has four broad stems; the PC AlbumDB directory holds derived 5.1 WAVs, while its original stem tree is on the NAS and only contributes a few TRAIN songs of one artist. Their import and domain effect deserve a **separate** comparison if this first intervention is promising. Mixing their addition into this run would prevent attributing the result to the new sampler. The 774 htdemucs pseudo labels are already in both arms' half/half distribution and retain their own possible leakage/teacher errors.
