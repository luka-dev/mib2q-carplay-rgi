## Required product and authority

Stereo input -> six actual transport slots -> factory Virtual Cabin. A natural,
independent supporting rear scene must coexist with preserved foreground, front
fidelity, balanced bass and reliable target execution. Foreground includes vocal
hooks, guitar/synth/growl leads, not just recognized singers. Family identity is
not placement permission. Unknown roles/contamination abstain; an always-muted
rear fails utility. Restoration retains original phase-bearing audio and must
be supported by source evidence; it is not an automatic front subtraction anchor.

Development, existing compute/storage use and package preparation are authorized.
Vehicle installation, factory writes, purchases, deletion of accumulated data,
external push and credential disclosure are not. Ordinary implementation changes
need no repeated user approval. A hardware/listening request must name the exact
missing action and must not block unrelated work.
