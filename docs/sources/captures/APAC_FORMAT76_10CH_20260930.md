# APAC format76 10-channel corpus

Imported on 2026-09-30 from the user-supplied `MHI2_ATMOS_SPATIAL_AI_MEMORY_v8.0_2026-09-30` package. This is a separate corpus from the existing MHI2Q format65 recording.

## 📦 Local contents

The corpus lives in `captures/apac_format76_10ch_20260930/`, excluded from Git like other private recorded audio. Import date is not an assertion of capture date.

| File | Contents |
| --- | --- |
| `apac_payloads/APAC_0001.bin` through `APAC_0256.bin` | 256 original extracted APAC access units, 256,496 bytes total |
| `magicCookie_dapa.bin` | Original 34-byte decoder cookie |
| `packets.list` | Relative access-unit paths in numeric decode order; resolve from the corpus directory |
| `SHA256SUMS` | Source-verified hashes of all 257 input files |
| `MANIFEST.json` | Format, provenance, per-file sizes and hashes |

Only decoder inputs were imported. Session keys, SETUP plists, reconstructed PCM, decoder sources and renderer packages were not copied. Input files retain their source names and bytes and have mode `0600`.

Source archive: `EVIDENCE/TYPE103_APAP_APAC/RESULT37_OFFLINE_APAP_SECURITY_APAC_CORPUS_v1.zip` inside the supplied v8 package. The source reports authentication/decryption of all 256 APAP records. Import independently verified the archive against the package manifest and every copied input against the archive's original `SHA256SUMS.txt`.

This import does not establish correct format76 PCM synthesis or extend the existing format65 decoder validation. The package's separate RESULT38/54 decoder produced acoustically incorrect PCM; that PCM is not a golden reference. No decoder, oracle or vehicle test was run during import.

From the corpus directory, verify the saved inputs with:

```sh
shasum -a 256 -c SHA256SUMS
```

The existing Pioneer oracle is documented in [reference/NOTES.md](../../../apac_decoder/reference/NOTES.md). Its format76 adaptation and decoder comparison remain deferred.
