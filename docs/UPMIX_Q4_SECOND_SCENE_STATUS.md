## Формулировка (принята Luka)

Цель: для любого жанра, с учётом Virtual Cabin, разделить стерео и вынести назад
часть как вторую сцену. Без классов инструментов. Тыл = НЕ защищённое (лид-вокал,
бас, ядро ударных, доминирующая линия) И широкое/раскоррелированное/текстурное.
Единственная обучаемая часть: **маска защиты** (что нельзя назад). Всё остальное DSP
и рендер (`cabin_balanced`: задержка тыла 10–20 мс, HP, доля вычитания из фронта).
Подробно: memory `upmix_second_scene_formulation.md`, аудит
`UPMIX_INDEPENDENT_AUDIT_2026-09-17.md`.

### Модель всего тракта (2026-09-19): мастер → рендерер → матрица банка 5.1

`tools/stereo-upmix-render/cabin_model.py`: 9 отрывков по 60 с из приватных мастеров (heldout + 2),
боевой рендер (q6d + guard, LFE assist, тыл 0,40, задержка 512 сэмплов учтена кросс-корреляцией),
точная матрица банка 1 (`SHARC_INPUT_OUTPUT_MATRIX.md`), шины до выходного EQ усилителя (режим
DSP «5.0» и выходные EQ не смоделированы — семантика не восстановлена).

- **Перегрузов нет.** Пики шин L/C −0,1…−1,4 dBFS (мастера сами на 0 dBFS, матрица не добавляет),
  тыловая шина −1,8 dBFS при 0,40 и **−0,1 dBFS при 0,50** (2·Ls: запаса нет, наш лимитер режет по
  PCM-потолку). Наш фронтальный PCM никогда не выше входа (−0,4 дБ = гейн 0,958). Тыл на потолке
  ≤0,03 % сэмплов.
- **Третья дверь с басом.** Центральная шина = 0,5·(L+R) + 0,316·LFE играет 20–250 Гц на
  −0,2…−1,7 дБ от входного L, то есть моно-бас современных мастеров идёт с полного уровня третьим
  динамиком. Это и есть «бас со всех колонок» при Bass 0. Полка −3 дБ (fb3): фронт 60–120 Гц
  −5,5…−6,0 дБ от входа (было −2,6…−2,9), центр −3,2…−4,6 (было −0,2…−1,7), LFE и тыл побитно те же.
- **Гребёнка от возврата тыла.** Усилитель возвращает 0,708·Ls (с нашей задержкой 12 мс) во фронт:
  отдельно измеренная от переноса рябь 300–3000 Гц ±3 дБ (pp 5,9–6,8 дБ, шаг 83 Гц). Неотделимо от
  матрицы; предкомпенсация (−0,891·rear_delayed во фронт) отвергнута ранее: центр получил бы
  противофазную задержанную копию.
- **Цена релокации.** Фронтальная шина теряет 2–6 дБ в 500 Гц–4 кГц на плотных мастерах
  (Boost Up 1–2 кГц −7,6 дБ с учётом матрицы −2 дБ); тыловая шина в этих полосах −2…−13 дБ от
  входа, активность тыла 36–95 % времени. Это и есть «сцена сзади»: чем больше ВАУ, тем пустее фронт.
- **Скачков и накачки нет.** После выравнивания задержки ни одного окна 50 мс, где фронт прыгает
  на >8 дБ без входа. Единственное «странное»: на гейтированной электронике (Deep Down Low) фронт
  дожёвывает стабы ~12 мс за счёт возврата тыла (по конструкции: задержка тыла + матрица).
- **LFE стабилен:** шина саба 20–60 Гц −6…−9 дБ от фронтального L, 60–120 −14…−19.

Вывод: аудио-тракт чистый, «лишний бас» это матрица усилителя (центр), лечится фронтальной полкой;
поднимать тыл выше 0,40 без запаса по тыловой шине не стоит, 0,50 = 0 dBFS пики.

## Sub level: the actual bass culprit (2026-09-19)

The 2026-09-18 build (ccb09c6) raised `SPA_STEREO_UPMIX_LFE_Q15_DEFAULT` from the
