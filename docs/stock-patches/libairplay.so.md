# libairplay.so: очереди видеодекодера

## 📦 Выбранный патч

Файл ГУ: `/mnt/app/eso/lib/libairplay.so`. В двух конструкторах глубина очереди команд декодера снижена с 4 до 2. Это уменьшает допустимое накопление работы на стороне ГУ для основного экрана и AltScreen; частоту отправки кадров iPhone эта правка не задаёт.

| P5087/MU1316 | Значение |
| --- | --- |
| Размер | 763420 байт, без изменения |
| Смещения файла | `0x8c694`, `0x8c6f4` |
| Изменение | В каждой точке `04` → `02` |
| SHA stock | `01c116b1674215daa0602d556a6d9b2eb48c2113ca294ea1f5d58787e3f656f2` |
| SHA patched | `a527b77800f690a33a8856e79e7f9d5a89143bfdd7108903837a444976be25b6` |

## 🔧 Механизм и установка

[binpatch.py](../../deploy/binpatch/binpatch.py), режим `airplay_decoder`, ищет обе полные окружающие сигнатуры. Поддержаны известные P5087/P5092; другой `libairplay` K1004 отвергается. Смещения выше относятся только к указанному P5087, переносить их на другой файл нельзя.

Установщик `patch_airplay_decoder` сохраняет `.carplay-stock`, пишет временный файл и заменяет путь через rename. Уже пропатченный файл даёт код 3 без нового результата; частичный патч, дубликат сигнатуры и неизвестный бинарник дают отказ. Для применения нужна новая загрузка библиотеки процессом: текущий mapping старого inode не меняется.

## 🧪 Проверка и пределы

`bash scripts/test_binpatch.sh` проверяет сигнатуры, повторы, частично изменённые файлы и точные изменения. [Каталог байтов](evidence/binary-patches.json) фиксирует результат. [decoder_optimize](../../hook/decoder_optimize/decoder_optimize_hook.c) содержит guarded runtime-попытку тех же двух правок. QNX может отказать в `mprotect` shared text, поэтому выбран дисковый патч. Это один эффект, его нельзя дважды учитывать как независимое ускорение.

Исходное ограничение AltScreen 15–27 FPS могло приходить от политики Maps на iPhone даже при обработке кадра быстрее frame time. [Профиль Maps 30 FPS](../altscreen-and-video/MAPS_30FPS_PROFILE.md) воздействует на эту политику отдельно. Размер очереди 2 сам по себе не гарантирует 30 FPS.
