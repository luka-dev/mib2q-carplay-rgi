# MCD: ограничение повторных сканирований

## 📦 Выбранный патч

Файл ГУ: `/mnt/app/armle/usr/sbin/mcd`. PATHSPACE-уведомления могли будить наблюдателей каталогов и приводить к повторным сканированиям всеми 13 детекторами. В соответствующем цикле ожидание через `sigwaitinfo` заменено на `delay(200)`: частота проверок каждого такого потока ограничивается примерно 5 Гц.

| Параметр P5087/MU1316 | Значение |
| --- | --- |
| Изменяемый диапазон файла | `0x7730`, 12 байт инструкций, 5 отличающихся байтов |
| Было | `860f8de20010a0e373ebffeb` |
| Стало | `c800a0e30010a0e3f7ebffeb` |
| Размер | 47039 байт |
| SHA stock | `f11d13ffec1322aefcfb431966180cff46c314320eeef7ed12470bfc441dd593` |
| SHA patched | `e18f3055f633c99b3f10022c1f0a9c61a9e597d8b9a95831e5578a2e5c5387ee` |

## 🔧 Конфигурация и компромисс

Для `/mnt/system/etc/mcd.conf` активное `Priority=11,10` меняется на `Priority=11,3`. Комментарии и список устройств, включая CD, сохраняются. Ограничение сканирования может добавить до одного интервала опроса плюс задержку планировщика к обнаружению изменения; это не строгая верхняя граница реакции всей системы.

Режим `mcd` в [binpatch.py](../../deploy/binpatch/binpatch.py), функции `patch_mcd` и `patch_mcd_conf` в установщике сохраняют штатные копии. Известные MCD трёх проверенных firmware byte-identical; неизвестную сигнатуру нельзя патчить вслепую. После замены требуется новый запуск MCD.

## 🧪 Проверка

`bash scripts/test_binpatch.sh` проверяет точные изменения бинарника и конфигурации. [mcd.custom](../../mcd/mcd.custom) соответствует патчу. Исторические CPU-значения зависят от нагрузки: этот документ не приписывает MCD фиксированное снижение CPU по сравнению с идентичным контрольным прогоном.
