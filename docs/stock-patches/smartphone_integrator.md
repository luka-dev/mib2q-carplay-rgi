# smartphone_integrator: исправление USB rearm

## 📦 Выбранный патч

Файл ГУ: `/mnt/app/eso/bin/apps/smartphone_integrator`. В обработке ошибки устройства исправляется направление повторного взведения: `MOV R3,#0` заменяется на `AND R3,R9,LR,LSR#6`. Это сохраняет нужное направление вместо безусловного нуля.

## 🔧 Воспроизведение и проверка

Режим `smartphone_integrator` в [binpatch.py](../../deploy/binpatch/binpatch.py) использует уникальную сигнатуру, а не фиксированный offset. Известные P5087, P5092 и K1004 проверяются тестом `bash scripts/test_binpatch.sh`. Установщик `patch_si` сохраняет штатный файл и атомарно заменяет результат; неизвестные файлы оставляет без изменения.

Смещения и SHA относятся к P5087. Активные изменения SI для wireless-протокола описаны [отдельно](../wireless-carplay/SI_WIRELESS_EXTENSION_PLAN.md): они не входят в указанные четыре байта и не подтверждаются этим тестом. Применение дисковой замены требует перезапуска использующего бинарник процесса.
