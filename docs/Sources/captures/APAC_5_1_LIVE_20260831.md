# APAC 5.1 live corpus — 2026-08-31

## Purpose

This is the non-secret manifest of a live wired-CarPlay recording from an Audi MHI2Q MU1316. The corpus itself is stored only
locally in `captures/apac_5_1_live_20260831_0205`; the directory is excluded from git because SETUP contains
the 32-byte `shk` session key in plaintext, and the APAP stream contains recorded program audio.

## Contents of the local corpus

- `spatial_apap_5.bin` — exact raw TCP recording of the audio stream from the HU;
- `spatial_setup103_5_request.bplist` — the matching type-103 descriptor and `shk`;
- `spatial_magiccookie_5_60100d08f9d19abb.bin` — the matching 33-byte `dapa` cookie;
- the SETUP response and the plists of the SETRATE, SETRATEANCHORTIME and FLUSHBUFFERED commands;
- a local `README.md` and `SHA256SUMS` for verifying all source artifacts.

## Final incomplete record

The full teardown stopped the recording immediately after the next four-byte inclusive-BE32 length
prefix. The parser therefore correctly reports that only four bytes remain after the offset of the final prefix.
This is not corruption of the preceding audio: the first 1,320,015 bytes contain 3980 complete
frames, and all of them pass ChaCha20-Poly1305 authentication.

The raw evidence must not be fixed or truncated. For offline decoder work, make a temporary
copy of the first 1,320,015 bytes and extract the key from the local SETUP. The current
`tools/pioneer_apap_decrypt.py` then confirms:

```text
frames=3980 verified=3980 failed=0 plaintext_bytes=1148875 modes=[extension12=3980]
```
