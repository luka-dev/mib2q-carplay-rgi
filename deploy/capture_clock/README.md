# Кандидат коррекции общего захвата VC (MU1316)

> **Эксперимент остановлен 2026-09-15. Не включать в выгрузку.**
> Пользователь подтвердил плавную штатную карту; причина менять общий
> capture timer не доказана. videoencoderservice остаётся штатным.
> Приведённые ниже команды сохранены как история, не как текущий план установки.

Этот комплект подключает `libvc_capture_clock.so` только к штатному
`videoencoderservice`. Коррекция касается приборки (display 4) и применима
как к altScreen, так и к maneuver renderer. Проверка фактических 30 FPS на HU
ещё не выполнена. При неподдерживаемом периоде библиотека возвращает 33 мс.

Установка выполняется отдельно от основного CarPlay-комплекта. Рендереры,
JAR, основной hook и их supervisor этот установщик не меняет.

## Перед применением

Только MHI2Q MU1316 с байт-в-байт совпадающим `videoencoderservice`.
Пакет собран после проверки SHA256 и ARM ABI; installer сверяет живой ELF
с проверенным `reference/videoencoderservice`, который **никогда не подменяет**
штатный executable. В пакете должен быть `manifest.json`.

`/mnt/app` и `/mnt/system` должны быть доступны для записи. Скрипт не
перемонтирует разделы и не перезапускает процессы. Используется существующий
`/mnt/app/armle/usr/bin/cmp` из этой прошивки; отсутствие утилиты останавливает
установку до изменений. awk, sed, jq, Python, pgrep и циклы мониторинга не нужны.

## Команды на HU после копирования комплекта

```sh
sh install.sh install
sh install.sh disable
sh install.sh uninstall
```

- `install`: устанавливает `.so` и короткий exec wrapper; заменяет только
  `exec` у `videoencoderservice` в framework.json; включает marker последним.
- `disable`: удаляет enable marker. На следующем запуске wrapper выполнит
  штатный encoder без добавления capture preload.
- `uninstall`: восстанавливает штатный exec только у этого сервиса, сохраняя
  остальные изменения framework.json; файлы оставляет неактивными на диске.

Действие этих команд относится к **следующему запуску encoder**. Уже работающий
процесс не перезапускается и не выгружает библиотеку. Перезапуск/reboot должен
быть отдельным действием при проверке на HU.

При неизвестной/дублированной записи сервиса изменение config отклоняется.
Публикация идёт через временный файл с сохранением mode/owner; повторная
установка идемпотентна. Исходный config сравнивается перед заменой, чтобы
не затереть замеченное параллельное редактирование.

Wrapper делает один `exec`, сохраняет PID и аргументы framework. Если marker
или библиотека отсутствуют, запускает сток. Если уже задан LD_PRELOAD, он
сохраняется; новый capture preload в этот запуск не добавляется. Глобальное
окружение, dio_manager и процессы обоих рендереров не затрагиваются.
