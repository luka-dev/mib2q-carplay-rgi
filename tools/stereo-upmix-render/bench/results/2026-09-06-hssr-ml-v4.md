# HSSR EDM/direct-surround ML checkpoint — 2026-09-06

The runtime network remains `368 -> GRU160 -> GRU160 -> 264`: 451,464
parameters, 449,280 int8 weight bytes and a 469,760-byte exported model.  No
target CPU, persistent RAM, control rate or audio latency changed.

## Training changes

- `edm-v2` keeps the six MUSDB semantic classes but adds rearability targets
  for spatially distinct mid/high percussion and synth objects.  It requires
  scene width plus local ILD/coherent-IPD evidence and retains lead/bass and
  low-frequency protection.
- Rear-positive target bins receive extra loss weight, avoiding the original
  low-rearability-everywhere optimum.
- A direct-surround cache uses a canonical fold of authored 5.1 as input,
  preserves semantic soft labels from the frozen EDM-v2 teacher, and measures
  rearability and steering from actual SL/SR.
- The downloaded research pool contains 45 locally ffprobe-verified six-channel
  files (3.073 hours, 2.90 GiB): two original CC0 electronic/glitch albums and
  one CC-BY film/effects master.  NoDerivatives and obviously mislicensed
  commercial DVD extracts were excluded.
- V4 uses one central 20-second excerpt per file, a conservative authored
  target, and `2e-4` warm-start learning rate.  The more aggressive V3 was
  rejected after independent evaluation.
