# Cabin-Aware LFE V2 — narrow 48-Hz sub-band

Date: 2026-09-08

## Decision

The 55/95-Hz body/punch pair was replaced in place by one per-side 48-Hz LR4
low-pass. There is no runtime profile or fallback to the wider path.

The SoundAmp B01 crossover catalog contains a paired 48-Hz entry interpreted as
the conservative subwoofer boundary, followed by low-frequency entries at
96 Hz. Exact filter-to-output binding is still inferred until the extracted
SHARC application is semantically disassembled. Using 48 Hz is intentionally
conservative: the recovered J525 matrix sends digital LFE not only to Bus_LFE
but also to front, centre and rear logical buses.

The Q15 `4096` (`0.125`) LFE ceiling, Q15 `31392` (`0.958`) paired front trim,
phase-correlation `L+R`/`L-R` choice, HSSR bass/drum level control and the exact
six-bus Cabin limiter are unchanged. Only LFE bandwidth was narrowed.

The new LR4 magnitude response is approximately:

```text
40 Hz    -3.42 dB
48 Hz    -6.02 dB
80 Hz   -18.81 dB
96 Hz   -24.61 dB
120 Hz  -32.06 dB
500 Hz  -81.43 dB
```

The exact old/new C render on settled equal-phase S16 tones confirms the
practical change, including semantic dynamics and quantization:

```text
frequency    LP48 versus retired LP55/LP95
40 Hz        -0.85 dB
48 Hz        -1.70 dB
80 Hz        -7.67 dB
96 Hz       -10.64 dB
120 Hz      -13.37 dB
500 Hz       quantizes to digital zero in LFE
```

## Held-out music A/B

Fourteen deterministic ten-second excerpts from the seven held-out local songs
were rendered with the exact previous 55/95-Hz binary and the new 48-Hz binary.
Both used HSSR Universal V11, rear `0.25`, LFE `assist`, and the same model.

```text

mean LFE energy fraction        0.2023%       0.1607%      -20.6%
mean LFE/front level           -25.831 dB    -27.738 dB    -1.907 dB
mean LFE sample peak           -27.140 dBFS  -29.850 dBFS  -2.710 dB
maximum LFE sample peak        -20.674 dBFS  -21.743 dBFS  -1.069 dB
maximum J525 matrix peak        -0.239 dBFS   -0.308 dBFS  +0.069 dB headroom
front preservation SNR          11.243 dB     11.243 dB     unchanged
fold-back SNR                   14.131 dB     14.131 dB     unchanged
clipped samples                       0             0
```

Rear metrics are unchanged because the HSSR rear renderer was not touched.
The ignored detailed reports are reproducible under:

```text

build/reference-audio/lfe-lp48-heldout-eval/
```
